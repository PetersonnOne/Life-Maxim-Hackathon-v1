# Life Maxim brand asset

Asset: `public/life-maxim-logo.png`. Created with the built-in image-generation tool on September 20, 2026; no application API key was used. The original generated file is preserved outside the repository. The shared BrandMark component uses the image beside real, accessible Life Maxim text, with a pale mint backing for contrast in both themes. It appears on the homepage, authentication pages and dashboard; metadata also uses it as the site icon.

Final generation prompt:

> Use case: logo-brand. Create a polished distinctive logo mark for Life Maxim, an intelligent life and work planning web app. Emerald and mint green palette, simple confident geometric symbol combining a rising path and a leaf/compass, conveying clarity, direction and personal growth. One centered compact icon only, no text, no letters, no mockup, no shadows, no tiny details. Strong silhouette readable at 32px, flat vector-like finish, genuinely transparent background. This will sit beside the live text Life Maxim on both dark emerald and light website headers.

Theme selection uses the existing `life-maxim-theme` preference: Emerald Dark or Light. Emerald remains the default and an explicit selection is preserved across reloads.
